# Visa Almaz Tour

Адаптивный сайт визового центра в Астане. Дизайн и шрифты соответствуют основному проекту AlmazTour: Segoe UI, тёмно-синий #000942, жёлтый #ffcc00, крупный фотобаннер, округлые карточки.
Разработка ведётся в этой папке отдельно от основного сайта.

## Запуск
Нужен Node.js 22.13+. Устанавливать npm-пакеты не требуется: Lenis включён в проект.

npm run dev
http://localhost:4173

npm test
npm run check
npm run build
npm start

Локальный Node-сервер запускается через scripts/dev-server.mjs. Для собственного Node-хостинга нужны HTTPS и SITE_ORIGIN в .env.
HOST=0.0.0.0 указывайте, если этого требует хостинг.
На Vercel dist отдаётся как статический сайт, а /api/config работает как отдельная Vercel Function из api/config.js. При локальном запуске этот endpoint обслуживает dev-server.
GitHub подключён к проекту Vercel visaalmaztourkz. Production-ветка: codex/visa-website. Публикация обновляется после push в эту ветку.

## Форма и WhatsApp
Основной номер: +7 706 406 0101. Дополнительный: +7 701 888 7932.
Форма запрашивает имя и направление. Поля телефона нет.
«Продолжить в WhatsApp» открывает чат основного номера с черновиком. Клиент проверяет текст и отправляет его сам. Его номер будет виден в переписке.
Форма не вызывает серверный API, не записывает данные в базу и не сообщает, что заявка уже отправлена.
Имя хранится только в текущем поле браузера до перехода в WhatsApp.

## Подготовленная серверная интеграция Cloud API
Сохранён POST /api/consultation для отдельного использования после настройки Meta. Текущая форма его не вызывает.
whatsapp.mjs отправляет шаблонное уведомление на заданный номер менеджера. Входящие вебхуки и интерфейс операторов пока не реализованы.

В .env, созданном по .env.example, нужны:
- WA_ACCESS_TOKEN: системный токен Meta с whatsapp_business_messaging.
- WA_PHONE_NUMBER_ID: ID подключённого к API номера +7 706 406 0101, не сам телефон.
- WA_NOTIFY_TO: другой номер менеджера, согласившегося получать уведомления. API-номер не может писать самому себе.
- WA_TEMPLATE_NAME и WA_TEMPLATE_LANGUAGE: имя и язык одобренного шаблона.
- WA_API_VERSION: версия Graph API, по умолчанию v26.0.

Шаблон использует три позиционных параметра BODY: имя, телефон, направление. Этот серверный контракт сохранён для будущей интеграции: телефон для него нужно получать из отдельного источника, например входящего WhatsApp-сообщения.
Ключи не попадают в браузер или сборку.
Без настроек endpoint возвращает 503. Успех означает принятие сообщения Meta, а не подтверждённую доставку.
Реальная отправка не проверялась; тесты имитируют только внешний HTTP-транспорт.
Лимит: пять запросов за десять минут с адреса подключения. За reverse proxy нужен отдельный доверенный механизм определения IP и распределённый лимитер.

Документация Meta:
https://developers.facebook.com/documentation/business-messaging/whatsapp/get-started
https://developers.facebook.com/documentation/business-messaging/whatsapp/templates/overview

## Карта
Google Maps iframe показывает БЦ Kaskad: Астана, Кабанбай Батыра 6/1, 5 этаж, офис 51/5.
Для дополнительного JavaScript API заполните GOOGLE_MAPS_API_KEY и включите Maps JavaScript API, Geocoding API и биллинг. Ключ нужно ограничить доменами сайта и используемыми API.
Браузерный ключ публичный по назначению. Серверные секреты для него не подходят.
В JS API адрес геокодируется, после чего добавляется маркер центра. С ключом нужно отдельно проверить точность и доступность API; без ключа работает iframe.

## Прокрутка и анимации
assets/lenis.mjs содержит Lenis 1.3.27 из основного проекта; лицензия находится в assets/lenis-license.txt.
motion.mjs управляет плавной прокруткой, появлением блоков, параллаксом баннера и окнами направлений.
Для touch остаётся нативная прокрутка. Клавиатурные переходы мгновенные. При reduced-motion движение отключается, включая изменение настройки во время просмотра.
Окно направления останавливает прокрутку фона и возвращает её после закрытия. Анимации используют transform и opacity.

## Конфигурация Vercel
vercel.json явно задаёт framework: null, npm run build и outputDirectory: dist. Браузерный entrypoint называется client.mjs. Локальный сервер находится в scripts/, чтобы Vercel не распознавал браузерный app.mjs или локальный server.mjs как production-сервер. Веб-обработчик api/config.js возвращает только публичный ключ карты; токены WhatsApp в ответ не попадают.
